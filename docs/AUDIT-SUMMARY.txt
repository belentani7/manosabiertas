📋 HALLAZGOS "NO OBVIOS"

1. XSS en Chat (línea 1171)
   └─ innerHTML con entrada usuario
   └─ Severidad: BAJA (local, no persistida)
   └─ Fix: usar textContent + sanitize

2. localStorage no encriptado
   └─ En shared computer: otro usuario ve tema/modo
   └─ Severidad: MÍNIMA (sin PII)
   └─ Fix: sessionStorage para modo/tema

3. i18n hardcoded
   └─ SUGGESTIONS solo inglés/español
   └─ Chat IA no reconoce chino/árabe/hindi
   └─ Severidad: MEDIA (degraded UX para 3B+ usuarios)
   └─ Fix: expandir SUGGESTIONS + traducción UI

4. Sin soporte RTL
   └─ Árabe, hebreo, farsi: layout roto
   └─ Severidad: MEDIA
   └─ Fix: `dir="auto"`, CSS flex-direction RTL

5. No hay CSP meta tag
   └─ Sin restricciones de fuentes en navegador
   └─ Pero: es SPA sin servidor (bajo riesgo)
   └─ Fix: agregar si se sirve desde servidor

6. localStorage podría ser explotado
   └─ En contexto compartido (laboratorio, café)
   └─ Severidad: BAJA
   └─ Impacto: cambio de tema/modo, no PII

7. Offline degradation
   └─ MetaBuscador requiere internet
   └─ Catálogo funciona OK
   └─ Severidad: BAJA (esperado)

8. Cuestiones culturales no consideradas
   └─ Colores pueden ofender en algunas culturas
   └─ Símbolos pueden ser inapropiados
   └─ Fechas festivas no respetadas
   └─ Severidad: MEDIA/ALTA (reputacional)
