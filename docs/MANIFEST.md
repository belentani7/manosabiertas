## 📞 SOPORTE Y PROBLEMAS

### Problema: CRT no aparece
**Solución:** DevTools → Settings → Rendering → Uncheck "prefers-reduced-motion"

### Problema: GSAP no carga
**Solución:** Sin internet (CDN). Usa modo LITE o carga fuera de línea.

### Problema: MetaBuscador devuelve 0 resultados
**Solución:** Algunas APIs pueden estar caídas. Prueba con otra query más común.

### Problema: Visor blanco/vacío
**Solución:** Banco envia X-Frame-Options. Verifica nota en modal + usa "Origen ↗"

### Ver más: **VALIDACION-CHECKLIST.md** sección Troubleshooting
